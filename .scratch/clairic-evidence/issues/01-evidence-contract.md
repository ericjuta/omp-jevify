# Freeze evidence identity and source ownership

Type: wayfinder:research
Status: resolved
Owner: Main
Blocked by: none

## Question

Which versioned source, occurrence, dependency, and ledger contract lets imported comments reach the existing inbox without representing supporting sources as coverage hits or weakening exact-line citations?

## Research scope

Read jv.extraction, review_queue, review_questions, delete_spans and evals/findings.py. Specify stable record IDs allocated before extraction, immutable captures plus live origins, exact UTF-8 bytes and code-point mapping, source roles, all required question dispositions, and model observations separate from deterministic facts. Distinguish source inventory completeness from unknown semantic claim recall. Assess helper loading before choosing a new Python module boundary.

## Proposed direction

Use explicit source registry entries and versioned evidence artifacts, with imported snapshots never eligible for deletion. A dependency change invalidates approval even if the primary unit and extracted string do not change. Preserve current standalone grading and old evidence interpretation; reject incompatible artifacts explicitly rather than reinterpreting them.

## Resolution evidence

Implemented versioned contracts in [evidence.py](../../../skills/jevify/evidence.py), exposed through the installed-relative helper loader. [ExecPlan 1](../../../plans/clairic-01-evidence-contracts.md) records exact spans, immutable snapshots, scope accounting and dependency validation. Provider-free smoke verified astral/CRLF mapping, retained missing fields and fresh-process contract drift. Submission manifests now carry the evidence dependency contract through run/adopt/resume; imported snapshots remain non-deletable. Packaged bridge proof is tracked separately, not implied by this decision.
